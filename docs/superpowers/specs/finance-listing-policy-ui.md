# Finance Listing and Policy Editor UI

## Approved design

Keep Listing Approvals as a table, improve row hierarchy with listing thumbnails, and present View Details as a post-like preview. Restyle the Policy Management edit modal and instruction panel with readable warm light surfaces and dark text.

## Requirements

- Listing rows show an image thumbnail when the record has a usable image URL, with a clear placeholder when it does not.
- Listing details show a larger image or placeholder, title, listing type, review status, price, branch, description, and available review note or recorded terms.
- The table remains usable on narrow screens through its existing horizontal scroll behavior.
- The policy editor uses legible cream/light panels, dark text, clear field borders, and distinct cancel/apply actions.
- Preserve existing approval actions, permissions, policy fields, validation, and save behavior.
- Keep changes scoped to Listing Approvals and the policy edit modal.
